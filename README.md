# Kristama - Personal Portfolio

Portofolio web pribadi yang modern, responsif, dan interaktif, dirancang khusus untuk merepresentasikan perjalanan, keahlian, dan proyek saya di bidang *Software Engineering* dan *AIoT*.

[Lihat Live Demo disini] (Masukkan Link Hosting Anda nanti, misal: https://Krees01.github.io/portfolio)**

## Fitur Utama
- **Dark/Light Mode:** Mendukung tema gelap dan terang dengan deteksi sistem otomatis.
- **Glassmorphism & Neon UI:** Desain antarmuka modern dengan kedalaman visual (*3D Tilt Cards*).
- **Interactive Canvas Background:** Latar belakang partikel dinamis yang merespons kursor *mouse*.
- **High Performance:** Dibangun 100% menggunakan HTML, CSS, dan Vanilla JavaScript (tanpa *library/framework* eksternal) untuk menjamin kecepatan muat (Load Time) dan *frame rate* 60fps.
- **Accessibility Friendly:** Menghormati pengaturan *Reduced Motion* pada OS pengguna untuk mematikan animasi berat secara otomatis.

## Teknologi yang Digunakan
- **HTML5** (Semantik & Terstruktur)
- **CSS3** (CSS Variables, Flexbox, CSS Grid, Animasi Keyframes)
- **Vanilla JavaScript** (Intersection Observers, DOM Manipulation, HTML5 Canvas)
